# 1. What is Linux?

Linux is an **open-source operating system kernel**.

In simple words:

> Linux is the core software that helps applications communicate with computer hardware.

For example:

```text
Application
    ↓
Linux Operating System
    ↓
Linux Kernel
    ↓
Hardware
```

The kernel manages important resources such as:

- CPU
- RAM
- Storage
- Network
- Processes
- Devices
- Files

---

# 2. Why Learn Linux?

Linux is extremely important in IT because a large number of:

- Web servers
- Cloud servers
- Application servers
- Database servers
- Containers
- DevOps environments
- CI/CD systems
- Network devices
- Monitoring systems

run on Linux.

### Example

Imagine an e-commerce application:

```text
Customer
   ↓
Website
   ↓
Load Balancer
   ↓
Linux Application Server
   ↓
Linux Database Server
   ↓
Storage
```

If the application suddenly becomes slow, an Application Support Engineer may need to log into the Linux server and investigate:

```text
CPU?
Memory?
Disk?
Process?
Service?
Network?
Logs?
```

That is why Linux is an important skill for Application Support.

# 3. Linux in Application Support

Application Support engineers commonly use Linux to:

- Check server health
- Check running processes
- Check services
- Read application logs
- Search log files
- Check disk usage
- Check memory usage
- Check CPU usage
- Check network connectivity
- Restart services
- Verify application files
- Execute application commands
- Investigate production problems

### Example

Suppose customers report:

> "The payment application is not working."

The support engineer connects to the server:

```bash
ssh support@server
```

Then checks:

```bash
systemctl status payment-service
```

Checks CPU:

```bash
top
```

Checks disk:

```bash
df -h
```

Checks logs:

```bash
tail -f /var/log/payment.log
```

Linux knowledge allows the engineer to investigate the problem.

# 4. What is a Terminal?

A **terminal** is a program that allows you to interact with a computer using text commands.

Instead of clicking buttons, you type commands.

Example:

```bash
pwd
```

The system returns something like:

```text
/home/student
```

The terminal is also called a:

- Terminal
- Terminal Emulator
- Command Line Terminal

Examples:

### Linux

- GNOME Terminal
- Konsole
- XTerm

### Windows

- Windows Terminal
- PowerShell
- Command Prompt

### macOS

- Terminal
- iTerm2

---

# 5. CLI vs GUI

There are two common ways to interact with an operating system.

## GUI

GUI means:

> Graphical User Interface

You interact using:

- Windows
- Buttons
- Icons
- Menus
- Mouse

Example:

```text
📁 Documents
📁 Downloads
📁 Pictures
```

You can double-click a folder to open it.

---

## CLI

CLI means:

> Command Line Interface

You interact by typing commands.

Example:

```bash
cd Documents
ls
```

---

## GUI vs CLI

| GUI                        | CLI                        |
| -------------------------- | -------------------------- |
| Uses mouse                 | Uses keyboard              |
| Uses graphical interface   | Uses commands              |
| Easy for beginners         | Requires command knowledge |
| Can consume more resources | Usually lightweight        |
| Good for desktop users     | Excellent for servers      |
| Difficult to automate      | Easy to automate           |

### Industry Example

A developer may use a GUI on their laptop.

But a production Linux server may not have a GUI at all.

You connect using:

```bash
ssh user@server
```

Then manage everything through the terminal.

# 6. What is a Shell?

A **shell** is a program that accepts commands from the user and communicates with the operating system.

Simple flow:

```text
User
  ↓
Shell
  ↓
Operating System
  ↓
Kernel
  ↓
Hardware
```

For example:

You type:

```bash
ls
```

The shell understands the command and asks the operating system to provide the directory contents.

---

# 8. What is Bash?

Bash stands for:

> **Bourne Again Shell**

Bash is one of the most widely used Linux shells.

It is commonly used for:

- Running commands
- Server administration
- Automation
- Shell scripting
- DevOps tasks
- Application support

Example:

```bash
#!/bin/bash

echo "Application Support Server"
```

Bash is especially important because many Linux servers use it as the default shell.

# 9. Terminal Prompt

When you open a Linux terminal, you usually see something similar to:

```text
student@linux-server:~$
```

Let's understand it.

```text
student@linux-server:~$
   │          │       │
   │          │       └── Current location
   │          └────────── Hostname
   └───────────────────── Username
```

Another example:

```text
root@server01:/var/log#
```

Here:

```text
root
```

is the user.

```text
server01
```

is the hostname.

```text
/var/log
```

is the current directory.

```text
#
```

usually indicates the root user.

A normal user commonly sees:

```text
$
```

# 10. Linux Command Structure

A basic Linux command generally looks like:

```bash
command
```

Example:

```bash
ls
```

A command can also contain options:

```bash
command option
```

Example:

```bash
ls -l
```

And arguments:

```bash
command option argument
```

Example:

```bash
ls -l /var/log
```

General structure:

```text
command + options + arguments
```

---

# 11. Commands, Options and Arguments

Let's understand this with an example.

```bash
ls -l /var/log
```

### Command

```text
ls
```

Means:

> List directory contents.

### Option

```text
-l
```

Means:

> Display detailed information.

### Argument

```text
/var/log
```

Means:

> Look inside this directory.

So:

```text
ls       -l        /var/log
│         │            │
Command   Option       Argument
```

# 12. Absolute and Relative Paths

Understanding paths is extremely important in Linux.

## Absolute Path

An absolute path starts from the root directory:

```text
/
```

Example:

```text
/home/student/project
```

This gives the complete location.

---

## Relative Path

A relative path is based on your current directory.

Suppose you are currently here:

```text
/home/student
```

And there is a directory:

```text
/home/student/project
```

You can use:

```bash
cd project
```

instead of:

```bash
cd /home/student/project
```

---

## Important Path Symbols

### `/`

Root directory.

```text
/
```

### `.`

Current directory.

```text
.
```

### `..`

Parent directory.

```text
..
```

### `~`

Current user's home directory.

Example:

```bash
cd ~
```

# 21. Root User and Normal User

Linux has different levels of access.

Two important concepts are:

### Normal User

Example:

```text
sahil
```

A normal user has limited permissions.

### Root User

Root is the superuser.

Username:

```text
root
```

Root has very high privileges.

---

## Why should we not always use root?

Because a mistake as root can cause serious problems.

For example:

```bash
rm -rf
```

can be extremely dangerous if used incorrectly.

In production environments, engineers normally use their personal account and elevate privileges only when required.

# 22. sudo

`sudo` allows an authorized user to execute a command with elevated privileges.

Example:

```bash
sudo systemctl restart nginx
```

Without `sudo`, a normal user may not have permission to restart the service.

---

## Real Industry Example

Suppose an Application Support engineer needs to restart an application service.

They may run:

```bash
sudo systemctl restart payment-service
```

Then verify:

```bash
sudo systemctl status payment-service
```

`sudo` permissions are usually controlled through Linux user/group configuration.

We will study this more in:

**4.2 User & Group Management**

and

**4.3 Permissions & Ownership**

# 23. Command Chaining

Linux allows multiple commands to be executed together.

---

## Using `;`

Example:

```bash
pwd; ls
```

Both commands execute.

---

## Using `&&`

Example:

```bash
mkdir test && cd test
```

The second command runs only if the first command succeeds.

This is very useful.

Example:

```bash
systemctl restart nginx && systemctl status nginx
```

Meaning:

```text
Restart nginx
     ↓
If successful
     ↓
Check nginx status
```

---

## Using `||`

Example:

```bash
systemctl restart nginx || echo "Restart failed"
```

If the restart fails, the message is displayed.

---

# 24. Pipes

A pipe uses:

```text
|
```

It sends the output of one command as input to another command.

Example:

```bash
ls | less
```

Another example:

```bash
ps aux | grep nginx
```

Meaning:

```text
ps aux
   ↓
List processes
   ↓
grep nginx
   ↓
Find nginx-related processes
```

Pipes are extremely important for Linux troubleshooting.

---

# 25. Input and Output Redirection

Linux allows command output to be redirected.

---

## `>`

Write output to a file.

```bash
echo "Hello" > test.txt
```

---

## `>>`

Append output.

```bash
echo "Another line" >> test.txt
```

---

## `<`

Use a file as input.

```bash
command < input.txt
```

---

## Practical Example

Suppose you want to save the current date:

```bash
date > current-time.txt
```

Then:

```bash
cat current-time.txt
```

You can see the saved output.
