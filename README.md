```text
                    👤 Customer

              ┌──────────┴──────────┐

              └──────────┬──────────┘
```

```text

     ↓
```

# 🏆 Golden Rules for Students

## Rule 1 — Don't Just Copy Commands

Understand:

```text
What?
Why?
How?
When?
```

---

## Rule 2 — Practice Yourself

Watching a command is not the same as running it.

```text
Watching ≠ Learning

Doing = Learning
```

---

## Rule 3 — Don't Fear Errors

Errors are part of engineering.

When you see:

```text
Permission denied
Connection refused
Command not found
Service failed
Disk full
Authentication failed
```

don't panic.

Ask:

> **"Why did this happen?"**

---

## Rule 4 — Learn Troubleshooting

Anyone can run:

```bash
systemctl restart nginx
```

A good engineer asks:

```text
Why did nginx stop?
What caused the failure?
Will restarting solve the root cause?
Could restarting make the problem worse?
```
