# Linux Groups — Interview Questions

## Beginner

1. Why do Linux groups exist?
2. What is a primary group?
3. What is a supplementary group?
4. How do you create a group?
5. How do you add a user to a group?

## Intermediate

6. Why use `usermod -aG`?
7. What does `getent group` do?
8. Why are groups useful for team-based access?
9. What is the setgid bit on a directory?

## Advanced

10. Design access for a development team sharing `/opt/project`.
11. Why might a user not immediately see a newly added group?
12. How would you audit group membership?
13. What security risks exist if users are added to privileged groups?
