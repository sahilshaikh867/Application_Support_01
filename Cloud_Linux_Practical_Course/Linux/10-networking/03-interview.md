# Linux Networking — Interview Questions

## Beginner

1. What is an IP address?
2. What is a port?
3. What is DNS?
4. What does `ip addr` show?
5. What does `ip route` show?
6. What does `ss -tulpn` show?
7. What does `curl` do?

## Intermediate

8. TCP vs UDP?
9. What is a default gateway?
10. What is localhost?
11. Difference between `127.0.0.1` and `0.0.0.0`?
12. How would you check whether port 8080 is listening?
13. How do you troubleshoot DNS?

## Advanced

14. Explain the packet path from a client to a server.
15. Why can an application work locally but fail remotely?
16. How do cloud security groups differ from Linux firewalls?
17. Explain connection states such as LISTEN and ESTABLISHED.
18. How would you troubleshoot intermittent network latency?
