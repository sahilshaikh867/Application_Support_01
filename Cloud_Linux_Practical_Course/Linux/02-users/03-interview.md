# Linux Users — Interview Questions

## Beginner

1. Where are Linux users recorded?
2. What does `whoami` show?
3. What does `id` show?
4. What is the root user?
5. What is `/etc/passwd`?
6. Why is `/etc/shadow` protected?

## Intermediate

7. Difference between `useradd` and `adduser`?
8. How do you change a user's shell?
9. How do you lock an account?
10. How do you check password aging?
11. How do you remove a user and home directory?

## Advanced

12. What is UID?
13. Why should service accounts generally have limited privileges?
14. What happens when a user is deleted but files owned by that UID remain?
15. How would you investigate an unexpected user account?
16. How would you disable access without immediately deleting the account?
