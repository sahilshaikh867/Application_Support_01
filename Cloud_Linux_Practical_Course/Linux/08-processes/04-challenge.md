# Linux Processes — Independent Challenge

## Objective

Complete this task without copying the practical lab step-by-step.

## Requirements

1. Create a separate lab environment.
2. Use only test users/files/processes.
3. Perform the task safely.
4. Verify the result.
5. Record the commands used.
6. Explain what happened in simple language.
7. Add one troubleshooting scenario.

## Viva

Explain:
- What problem you solved.
- Which Linux concept you used.
- Why your commands were safe.
- What could go wrong in production.
- How you would monitor or verify the result.
