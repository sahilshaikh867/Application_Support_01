# Linux Administration Capstone — Notes

This capstone combines the major Linux topics covered in the course.

The goal is not command memorization. The goal is to think like a Linux administrator.

You will combine:

- Users
- Groups
- Directories
- Permissions
- ACLs
- Processes
- Scheduling
- Networking
- Logs
- Archive/compression

## Scenario

A company has a small application server.

You must create:
- Application user
- Development group
- Shared application directory
- Secure permissions
- ACL-based exception
- Health-check script
- Scheduled health check
- Backup archive
- Basic network verification

## Expected Thinking

Before changing anything:

1. What is the requirement?
2. Who needs access?
3. What is the minimum permission?
4. How will I verify it?
5. How will I troubleshoot it?
6. How will I clean it up?
