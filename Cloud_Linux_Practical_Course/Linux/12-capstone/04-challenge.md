# Linux Capstone — Production Thinking Challenge

## Build a Mini Production Server

Design and implement a controlled lab server for a fictional application.

### Requirements

- Dedicated application user
- Development group
- Least-privilege permissions
- ACL exception
- Application log directory
- Health-check script
- Scheduled health check
- Backup archive
- Network verification
- Basic troubleshooting documentation

### Rules

You may not:
- Use `chmod 777` as a solution.
- Run the application as root without justification.
- Use `kill -9` as the first troubleshooting step.
- Store passwords directly in scripts.
- Leave unnecessary cron jobs running.

### Final Interview

Explain your design to an interviewer as if you were the Linux/DevOps engineer responsible for the server.
