# Directories & File Management — Interview Questions

## Beginner

1. What is `/`?
2. What is `/home`?
3. What is `/etc`?
4. What is `/var/log`?
5. Difference between `cp` and `mv`?
6. How do you create directories?
7. How do you find a file?

## Intermediate

8. What does `find -type f` mean?
9. What does `-r` mean in many file commands?
10. Difference between `rm` and `rmdir`?
11. How do you inspect file metadata?
12. What are file timestamps?

## Advanced

13. Why is `/var` different from `/etc`?
14. How would you safely delete a large directory?
15. How would you find files larger than a specific size?
16. How would you find recently modified log files?
