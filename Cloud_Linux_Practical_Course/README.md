# Cloud Computing & Linux Practical Course

A level-wise, beginner-friendly practical course designed for classroom training.

## Course Structure

Each topic contains:

1. `01-notes.md` — Concept notes in natural language.
2. `02-practical.md` — Guided practical lab from zero to verification.
3. `03-interview.md` — Interview questions from Beginner → Intermediate → Advanced.
4. `04-challenge.md` — Optional independent challenge for students.

## Recommended Lab Method

For every practical:

**Understand → Prepare → Execute → Verify → Troubleshoot → Clean Up → Explain**

Students should not blindly copy commands. They should understand what each command changes.

## Linux Environment

Recommended:
- Ubuntu Server 22.04/24.04 LTS
- AWS EC2 Ubuntu instance or local VM
- SSH access
- A non-root sudo user

> Use `sudo` only when required. Never perform classroom experiments on a production server.

## Cloud Environment

AWS is used for examples because it is widely used in industry. The same concepts apply to Azure and GCP.

Always delete cloud resources after a lab when they are no longer required to avoid unnecessary charges.
